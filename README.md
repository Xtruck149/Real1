# Proposition RealSpill — Restaurant-Lounge 25/8 (Angré, Abidjan)

Proposition commerciale **indépendante**, préparée sans commande ni validation de l'établissement.
Rien n'est publié ; ce dépôt doit rester **privé**.

- [`maquette/`](maquette/) — site Next.js + TypeScript + Tailwind CSS (6 pages + page de transparence).
  Installation, architecture et vérification : [`maquette/README.md`](maquette/README.md).
- [`maquette/INFOS-A-OBTENIR.md`](maquette/INFOS-A-OBTENIR.md) — informations publiques trouvées
  (avec sources et contradictions) et liste de ce qu'il faut obtenir avant toute mise en production.

Démarrage rapide :

```bash
cd maquette && npm install && npm run dev   # http://localhost:3000
```
